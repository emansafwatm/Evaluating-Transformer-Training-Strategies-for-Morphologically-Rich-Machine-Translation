# Evaluating-Transformer-Training-Strategies-for-Morphologically-Rich-Machine-Translation
Machine translation between Arabic and English poses significant challenges due to profound linguistic, morphological, and syntactic differences. This study evaluates the performance of transformer-based models for bidirectional translation using the OPUS-100 benchmark dataset. Results indicate that transformer architectures achieve competitive performance in both directions, with improvements linked to language-specific preprocessing. The findings underscore the limitations of conventional evaluation metrics for morphologically rich languages and emphasize the need for enhanced morphological modeling, syntax-aware designs, and semantically informed evaluation to improve Arabic neural machine translation.
